# Typography

Part of the Fan Led X brand set. See [BRAND.md](BRAND.md).

The deck's brief: *"Oversized headlines with clear hierarchy."*

---

## Typeface

**Inter**, and nothing else. It is free under the SIL Open Font License, so it can be used
in any medium:

- **Web:** Google Fonts, or `@fontsource-variable/inter`
- **Desktop, decks and documents:** install Inter from rsms.me/inter or Google Fonts
- **Fallback** (only where Inter can't be embedded, e.g. plain email): Arial / Helvetica

Montserrat was used on an earlier version of the website and has been retired. Don't
reintroduce it.

## Weights

| Weight | Use |
|---|---|
| **Black (900)** | Headlines and card titles. This is the brand voice in type |
| **Extra Bold (800)** | Eyebrows, buttons, uppercase statement lines, emphasis lines in body |
| **Bold (700)** | Nav, small headings, inline emphasis |
| **Semi Bold (600)** | Softer two-tone headlines (navy + blue), lead emphasis |
| **Medium (500)** | Lead paragraphs, captions on dark grounds |
| **Regular (400)** | Body copy |

The **logo wordmark** is a heavy italic and is artwork, not typed text. Don't set "Fan Led"
in italic Inter to fake it. Use the logo file.

## Scale

Measured from the 1440px desktop website frames. For other media, keep the **ratios**:
the headline is about 3× body, the section heading about 2× body.

| Role | Weight / size / leading / tracking | Case |
|---|---|---|
| Display / hero | Black 60 / 110% / 0 | Sentence |
| Section heading | Black 36 / 105–110% / 0 | Sentence |
| Two-tone heading | Semi Bold 34 / 100% / 0 (navy + blue) | Sentence |
| Statement band | Extra Bold 34 / 120% / -1px | **UPPER** |
| Card / slide title | Black 25–30 / 110% | Sentence or Title |
| Lead | Medium 20 / 135–150% | Sentence |
| Body | Regular 16–18 / 150% | Sentence |
| Emphasis line | Extra Bold 16 | Sentence |
| Button / nav / eyebrow | Bold–Extra Bold 12–15, +4–8% tracking | **UPPER** |
| Caption / label | Medium 14 / 18px | Sentence |

## Case rules

- **Headlines are sentence case**, usually ending with a full stop. *"Three connected
  pillars. One operating system. Built around people."*
- **Uppercase is reserved** for eyebrows, buttons, nav, statement bands and venue names set
  over photography ("ROD LAVER ARENA").
- Card titles for the service pillars may use title case: *"Strategy, Commercial &
  Operating Models"*.
- Headline tracking is **0**. Only uppercase statements tighten (-1px), and only
  small uppercase labels open up.

## Two-tone headlines

A headline is often split across two colours to land the second idea:

- On dark: white, then **lime**. *Operations built around people. **Experiences that turn
  guests into fans.***
- On light: navy or black, then **electric blue**. *Fans don't experience your
  organisation in departments. **They experience it as one journey.***

Split at a sentence break, never mid-sentence.
